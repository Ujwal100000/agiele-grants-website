# Agiele Funding Website

Static site for Agiele Funding: grant research, writing, and management across all 50 U.S. states.

## Deploy

Any static host works (e.g., Netlify). Publish the repository root; entry point is index.html.

## Structure

- 11 pages: index, services, industries, process, case-studies, states, about, faqs, contact, privacy, terms
- favicon.svg, og-image.png (social share card), vitlycare-logo.png (case study)
- Contact form posts to an external API endpoint (lead database)
